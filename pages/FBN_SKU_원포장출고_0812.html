알럿은 판매자가 결과를 예상할 수 없는 변경에만 노출합니다.
  • 출고 포장 변경 → 알럿. 다른 모듈에 있는 별개 라벨의 값이 바뀌므로
  • 검품 방식 변경 → 알럿. 그 행에 박스 재포장 값이 노출되지 않으므로
  • 검품 유형(프리셋) 선택 → 알럿 없음. 카드에 박스 재포장 값이 이미 표시되어 인지한 선택이므로

  • 잠긴 상태에서는 알럿 유무와 무관하게 사유 안내를 항상 노출

C1아무 프리셋 클릭위 ① 표대로 6개 값 일괄 세팅X — 카드에 결과 값이 표시되어 인지한 선택

프리셋 카드에는 박스 재포장: 설정안함처럼 결과 값이 이미 표시돼 있습니다. 그 값을 보고 누르는 것이므로 확인창이 필요하지 않습니다. 다만 잠기는 경우 사유 안내는 항상 노출합니다.

실패 시 실패내역 엑셀에 원포장 출고와 박스 재포장 조합 오류 사유가 노출됩니다. 기본값은 원포장 출고=N · 박스 재포장=설정안함이고, 원포장 출고 컬럼은 skuBulkEditTemplate(일괄수정) · SKU_BULK_UPDATE_failure(실패내역) · skuInformationList(조회목록) · SKU_History(수정이력)에 추가됩니다.
검수 의견 · 실패내역 엑셀의 오류 사유 문구는 이번 검수 범위에 포함되지 않았습니다. 판매자가 엑셀로 대량 수정하다 실패하면 사유 문구만으로 원인을 찾아야 하므로, 문구 검토가 필요하면 공유 부탁드립니다.

  • 일반은 판매자센터에 노출되지 않는 브랜드 포장재 사용과의 대비어입니다(정책 위키: 판센·외부사 API 미노출, IIMS·물류사 API로만 등록). 판매자 화면에서는 짝을 잃어 무엇과 다른 일반인지 알 수 없습니다.
  • 출고 포장의 물류센터 박스 출고와 같은 지칭을 쓰면 두 설정이 같은 박스를 가리킨다는 것이 드러납니다.
  • 나중에 브랜드 포장재 사용이 판매자센터에 열릴 때 물류센터 박스 ↔ 브랜드 포장재로 대비가 자연스럽게 성립합니다.
  • 8월 반품 과제로 이미 배포된 기존 항목이라, 이번 개발 범위가 아니면 별도 과제로 검토를 요청드립니다.

입고된 재고 전체를 다시 확인하는 작업. 소비기한 관리여부를 나중에 바꾸면 이 작업이 필요해 비용이 청구됩니다.
기획 확인 필요
① 출고 포장 툴팁 — 정책·와이어프레임에 툴팁 내용이 정의돼 있지 않습니다. 제안 문구로 채워도 될지 확인 부탁드립니다.
② 비활성 영역 인라인 안내 — 8/19 개발 범위에 문구 추가가 가능한지 확인 부탁드립니다.
③ 알럿 스타일 분리(에러 ↔ 재확인) — 디자인 검토(@김준성) 결과에 따라 달라집니다.
④ 무게 오류 문구 단위 분기 — 선택 단위(kg·g)에 따라 문구를 바꾸는 것이 개발 가능한지 확인 부탁드립니다.
⑤ 라벨 변경 범위 — 화면 라벨만 출고 포장으로 제안하며 API 필드명(originalPackagingShipmentYn)·엑셀 컬럼명은 그대로 둡니다. 정책 문서·CS 가이드도 함께 정렬이 필요한지 확인 부탁드립니다.
⑥ 출고비 차이 — 상품 포장 그대로 출고 선택 시 출고비가 실제로 낮아지는지 확인 중입니다. 차이가 있다면 툴팁에 유인으로 명시하는 것을 제안합니다(아마존 SIPP는 주문 처리 수수료 할인을 명시적 유인으로 사용).
⑦ 엑셀·API 값 정렬 — 일괄수정 엑셀·실패내역 엑셀·API가 설정함(Y)/설정안함(N)으로 문서화돼 있습니다. 화면만 서술형으로 바꾸면 엑셀로 일괄수정하는 판매자가 두 표기를 오가며 매칭해야 합니다. 엑셀 컬럼 값·실패 사유 문구까지 함께 정렬할지 확인 부탁드립니다(9/16 배포 범위).
⑧ 대상 범위 — 박스가 아닌 포장(비닐 랩, 파우치, 포대)도 상품 포장 그대로 출고 대상인지 확인 부탁드립니다. 대상이라면 값에 박스를 쓰면 해당 판매자가 스스로 제외되므로 포장으로 표기해야 하고, 박스만 대상이라면 상품 고유 박스 출고가 더 정확합니다.
⑨ 프리셋 표시 유지 여부 — 검품 유형 박스 재포장·리퍼(등급화) 분류를 선택한 뒤 박스 재포장 값만 설정안함으로 초기화되면, 검품 유형 표시가 그대로 유지되는지 직접 설정하기로 바뀌는지 확인 부탁드립니다. 모달 비교표에 검품 유형 행을 넣을지가 여기서 결정됩니다.
⑩ 프리셋 충돌 처리 — 출고 포장이 물류센터 박스 출고인 상태에서 검품 유형 박스 재포장·리퍼(등급화) 분류를 선택하면, 그 유형의 기본값(박스 재포장 = 일반 박스 사용)이 제약과 충돌합니다. 정책에 정의가 없어 검수본은 제약 우선(설정안함 유지 + 이유 안내)으로 구현했습니다. 실제 동작 확인 부탁드립니다.
⑪ 정책 문서 표현 — 이 검수본의 화면 동작은 8/12 검토 요청 메일 기준으로 구현했습니다.
