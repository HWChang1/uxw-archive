상품 포장 출고
상품의 자체 포장 상태 그대로 출고하는 것. 판매자에게는 박스를 추가하지 않고 그대로 보낸다로 전달해야 합니다.
기존 표기: 원포장 출고 · 정책상 단수·SIOC · 아마존 동일 개념: 상품 포장 배송(SIPP) · API 필드 originalPackagingShipmentYn
박스 재포장
반품된 상품을 새 박스에 다시 담아 재판매 가능 상태로 만드는 서비스. 상품 포장 출고 설정함 상품만 대상입니다.
리퍼(등급화)
반품 상품의 상태를 등급으로 나눠 재판매 여부를 분류하는 것.
전수조사
입고된 재고 전체를 다시 확인하는 작업. 소비기한 관리여부를 나중에 바꾸면 이 작업이 필요해 비용이 청구됩니다.
기획 확인 필요
① 상품 포장 출고 툴팁 — 정책·와이어프레임에 툴팁 내용이 정의돼 있지 않습니다. 제안 문구로 채워도 될지 확인 부탁드립니다.
② 비활성 영역 인라인 안내 — 8/19 개발 범위에 문구 추가가 가능한지 확인 부탁드립니다.
③ 알럿 스타일 분리(에러 ↔ 재확인) — 디자인 검토(@김준성) 결과에 따라 달라집니다.
④ 무게 오류 문구 단위 분기 — 선택 단위(kg·g)에 따라 문구를 바꾸는 것이 개발 가능한지 확인 부탁드립니다.
⑤ 리퍼(등급화) 초기화 여부 — 정책 문서에는 설정안함 시 박스 재포장 제약만 명시돼 있고 리퍼(등급화) 언급이 없습니다. 프리셋 해제 시 리퍼도 함께 초기화되는지에 따라 모달에 표시할 항목이 달라집니다.
⑥ 라벨 변경 범위 — 화면 라벨만 상품 포장 출고로 제안하며 API 필드명(originalPackagingShipmentYn)·엑셀 컬럼명은 그대로 둡니다. 정책 문서·CS 가이드도 함께 정렬이 필요한지 확인 부탁드립니다.
⑦ 출고비 차이 — 상품 포장 출고 설정 시 출고비가 실제로 낮아지는지 확인 중입니다. 차이가 있다면 툴팁에 유인으로 명시하는 것을 제안합니다(아마존 SIPP는 주문 처리 수수료 할인을 명시적 유인으로 사용).
