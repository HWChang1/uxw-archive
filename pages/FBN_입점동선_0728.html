배경 & 변경 내역
🗂 배경
Problem

7/8 베타의 신청 동선에 중복 신청 과정(커머스솔루션 추가+신청정보 입력, 질의서+입고신청), 분산된 설정(상품·SKU 등록 ↔ 풀필먼트·배송속성), 물류사 시스템 이탈 경험이 남아 있어 신청→첫 판매 리드타임이 평균 33.4일(7/1 기준).

Current

9월 정식 출시에서 질의서 단계 삭제(초도입고 SKU를 신청 단계에서 등록) + 물류사 온보딩 삭제(시스템 자동가입)로 5단계→4단계(신청 → 물류사 연동 → 입고 준비 → 판매 개시) 간소화. KPI: 리드타임 16일 목표.

Hypothesis

단계가 줄어든 대신 신청 1단계의 정보 부담(최초 입고 SKU)과 선행 조건(상품·SKU 등록)의 비가시성이 새 병목이 된다 — 선행 조건을 동선 위에 노출하고, 단계별 안내를 실제 행동(무엇을 어디서)으로 구체화하면 이탈 없이 완주 가능.

📐 구조 제안 — 상품·SKU 등록을 어디에 둘 것인가

최초 입고 SKU '불러오기'는 SKU 필수정보 입력 + 연결상품 1개 이상이 선행돼야 작동하지만, 현재 4단계 어디에도 이 선행 작업이 보이지 않는다. 두 가지 대안:

ⓐ Step 1에 '상품·SKU 준비' 명시(5단계화 or 1단계 분할)
  • 선행 조건이 구조적으로 드러남 — 발견성 최상
  • 스텝 수 증가 → 심리적 부담↑ (기획 우려와 동일)
  • 이미 등록을 마친 판매자에겐 불필요한 단계
ⓑ 4단계 유지 + Step 1 내부에서 해결 권장
  • 최초 입고 SKU 영역 상단에 선행 조건 배너(상품·SKU 등록 여부에 따라 분기)
  • 미등록 판매자의 empty state에 상품 등록·SKU 등록 CTA 직결
  • 스텝 부담 없이 카피·분기로 발견성 보완 — 등록 완료 판매자는 방해받지 않음

※ ⓑ 기준으로 신청하기 탭에 마킹했고, ⓐ 채택 시 스텝퍼 구조 변경안을 별도 제안 가능.

[N배송 FBN 신청] 물류센터 상품 유형 정보에는 어떤 항목을 입력해야 하나요?
물류센터 상품유형정보는 네이버에서 판매자님에게 가장 적합한 물류사를 선정하기 위해 필요한 정보들입니다.
해당 정보가 누락되었을 시, N배송 FBN 신청이 불가할 수 있으니 반드시 모든 정보를 입력해주세요!
필요 항목은 아래와 같습니다.
[STEP 1. 운영 기초 정보]
▶ 월 평균 주문건수
N배송 FBN으로 판매하실 상품들의 한 달 평균 주문 건수를 입력합니다.
예) A상품 1,000건 + B상품 500건 = 1,500건 입력
※ 물류사 배정의 핵심 기준이 되므로 최대한 정확하게 작성해 주세요.
▶ 포장 방식 비중 (합계 100%)
- 단수: 입고된 박스에 송장만 붙여서 그대로 출고 (별도 포장 없음)
- 단포: 입고 박스에서 낱개 1개를 꺼내 새 박스에 포장하여 출고
- 합포: 여러 상품(SKU)을 한 박스에 함께 담아 출고
※ 세 가지 비중의 합이 반드시 100%가 되도록 작성해 주세요.
▶ 박스 사이즈 비중 (합계 100%)
출고되는 박스 크기 비율을 입력합니다. (세 변의 합 기준)
- 극소: ~80cm / ~2kg
- 소: ~100cm / ~5kg
- 중: ~120cm / ~10kg
- 대: ~140cm / ~15kg
- 특대: ~160cm / ~20kg
※ 세 가지 비중의 합이 반드시 100%가 되도록 작성해 주세요.
[STEP 2. 상품별(SKU) 정보]
▶ SKU명(옵션단위)
옵션별로 각각 한 줄씩 입력합니다.
예) '네이버 에센스 50ml', '네이버 에센스 100ml' → 2줄 입력
▶ 온도대
드롭박스에서 선택: 1.상온 / 2.저온(냉장) / 3.저온(냉동)
※ 냉장·냉동 상품은 반드시 파렛트 입고로 진행해야 합니다.
▶ 입고 형태
드롭박스에서 선택: 1.파렛트(PLT) / 2.파렛트(혼적) / 3.박스
※ 한 신청서 내 상품은 모두 같은 입고 형태여야 합니다. 혼용 불가합니다.
